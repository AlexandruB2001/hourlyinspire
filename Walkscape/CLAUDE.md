# Walkscape: notes for Claude Code

- Domain logic: `Packages/WalkscapeKit` (Foundation only). Run its tests with `swift test`, or on Linux with
  `docker run --rm -v "$PWD":/pkg -w /pkg swift:6.0-noble swift test` from that directory.
- iOS app: `Walkscape/` (SwiftUI, iOS 17). The project is generated by XcodeGen from `project.yml`; don't commit `.xcodeproj`.
- Without Xcode, the app target can only be compiled in CI (`.github/workflows/walkscape.yml`, macOS job).
- Art preview: `swift run pixel-preview <dir>` writes PPM images; convert with Pillow to view.
- Distances are integer metres. Never add Core Location or GPS features.
- Keep `docs/CHECKLIST.md` updated as milestones progress.
