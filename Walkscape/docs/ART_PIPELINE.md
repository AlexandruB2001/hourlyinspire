# Art pipeline

Everything you see is generated by `Packages/WalkscapeKit/Sources/PixelArt`.
It is original and needs no licence.

| Asset | Where | Format |
|---|---|---|
| Adventurer (6 palettes, 4 walk frames + idle, portrait) | `CharacterSprites.swift` | 16×20 text grid + palette keys |
| Items and achievements | `ItemSprites.swift` | 10×10 text grids |
| Zone scenes | `SceneRenderer.swift`, `BiomeScenes.swift` | Procedural parallax layers per biome |

## Scale

One art pixel = `Theme.pixel` (3 pt) in the Journey scene, 2.5 pt on the
friend track. Images are drawn with `.interpolation(.none)`. Scenes render at
view size ÷ pixel size, so they stay crisp on every iPhone.

## Previewing

```sh
cd Packages/WalkscapeKit
swift run pixel-preview preview-output
```

## Replacing with hand-drawn PNGs

`PixelArtCache` looks in the asset catalog before generating anything. Add
PNGs to `Walkscape/Resources/Assets.xcassets` with these names, with *Preserve
Vector Data* off and *Scales* set to "Single Scale":

| Name | Size | Notes |
|---|---|---|
| `character_<avatar>_walk_0` … `_walk_3` | 16×20 | facing right, transparent, feet on the bottom row |
| `character_<avatar>_idle` | 16×20 | |
| `portrait_<avatar>` | 16×12 | head and shoulders |
| `item_<spriteID>` | 10×10 | see `ItemSprites.allIDs` |
| `thumb_<biome>_<w>x<h>` | as named | still scene thumbnails |

Avatar IDs: `fern`, `sky`, `ember`, `plum`, `sunny`, `frost`.

Parallax scene layers are still generated. To use painted layers, extend
`PixelArtCache.scene` to load `scene_<biome>_{sky,clouds,far,mid,ground}`
images and tile them the same way.

## Adding a zone

1. Add a `Biome` case and a painter in `BiomeScenes.swift` (or reuse a biome).
2. Add the zone to `ZoneCatalog.standard`, or load a JSON catalog
   (`ZoneCatalog` is `Codable` and validated on decode).
3. Add an item sprite if the zone has a discovery.
